# Лабораторная работа: Исследование уязвимостей веб-приложений

## 1. Описание проекта

Данный проект представляет собой учебное веб-приложение на Python, предназначенное для изучения уязвимостей веб-приложений, а также демонстрации способов их обнаружения и устранения.

В рамках лабораторной работы реализованы три версии приложения:

- **app.py** — безопасная версия веб-приложения, в которой устранены рассматриваемые уязвимости.
- **appxss.py** — версия веб-приложения с уязвимостью Stored XSS (хранимая межсайтовая скриптовая атака).
- **appsqlxss.py** — версия веб-приложения с двумя уязвимостями: SQL Injection (SQL-инъекция) и Stored XSS.

## 2. Структура проекта

| Файл | Описание |
|---|---|
| `app.py` | Безопасная версия веб-приложения |
| `appxss.py` | Версия с уязвимостью Stored XSS |
| `appsqlxss.py` | Версия с SQL Injection и Stored XSS |
| `exploit.py` | Скрипт для проверки уязвимостей |
| `changes.diff` | Файл с изменениями исходного кода |
| `изменения.docx` | Документ с пояснениями внесённых изменений |

| `.gitignore` | Список файлов и папок, исключённых из Git |
| `скриншоты запусков.docx` | Скриншоты запусков кода |

## 4. Установка и запуск

### Требования

Для запуска проекта необходим установленный Python.

### Создание виртуального окружения

Windows:

```bash
python -m venv .venv
```

### Активация виртуального окружения

Windows:

```bash
.venv\Scripts\activate
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

Для запуска нужной версии приложения выполните соответствующую команду:

```bash
python app.py
```

Для запуска версии с Stored XSS:

```bash
python appxss.py
```

Для запуска версии с SQL Injection и Stored XSS:

```bash
python appsqlxss.py
```

Примечание: перед запуском другой версии приложения рекомендуется остановить уже работающий экземпляр.

## 5. Проверка уязвимостей

Для проверки предусмотрен отдельный скрипт `exploit.py`.

Он предназначен для проверки поведения приложения и демонстрации рассматриваемых уязвимостей.

Проверку следует выполнять только на локальном экземпляре учебного приложения.

Запуск:

```bash
python exploit.py
```

## 6. Описание исследуемых уязвимостей

### Stored XSS

Stored XSS — уязвимость, при которой внедрённый JavaScript-код сохраняется приложением и впоследствии выполняется в браузере пользователей при отображении сохранённых данных.

### SQL Injection

SQL Injection — уязвимость, возникающая при небезопасном формировании SQL-запросов. Она может позволить злоумышленнику изменить логику выполнения запросов к базе данных.

В результате лабораторной работы реализованы и рассмотрены:

- Скрипт для проверки уязвимостей.
